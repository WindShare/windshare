# Current Playwright Plan Impact Audit

Status: decision gate. This audit applies the current `docs/Playwright修复执行计划.md` baseline. No listed deletion or rewrite is authorized until this report is approved.

## Decision rules

- Line 99 removes the hosted/container-specific OCI authority, dependency-volume sealing, nonce retirement, containment validation, empty-readiness, and multi-layer publication systems.
- Line 103 defers the standalone scheduled/manual network workflow until a real fixture exists.
- Line 104 still requires the narrow native network-matrix publication boundary: an explicit publisher path, an explicit Windows Job helper path on Windows, and a helper manifest that binds those exact paths to SHA-256 values.
- Line 105 keeps blocking and full local browser gates Docker-free and removes the Docker reproduction subsystem.
- A random private staging name inside one native no-replace publication is an implementation detail, not the retired persistent nonce-authority system.

## Immediate consistency issue

The working tree is intentionally paused in a transient state. `publisher-helper-process.ts` currently accepts only `helperManifestPath`, while `main.ts` still supplies the two explicit helper paths. Do not freeze or publish this state. The approved reconciliation should require all of:

```text
--helper-manifest FILE
--publisher-helper FILE
--windows-job-helper FILE   # Windows only
```

The held canonical manifest must authorize the same platform-exact paths and expected SHA-256 values; the runtime must reject missing, extra, swapped, or mismatched entries before registry loading or runtime bootstrap.
