# Workspace ZIP recommendation benchmark specification

This is the historical measurement contract, not evidence and not threshold authority. The acquisition
automation and raw receipts are not distributed with WindShare.

- Freeze the tracked source. Record before/after tracked-file, mode, staged-diff, unstaged-diff, repository-local dependency, plan, reviewed epoch-policy, and support-matrix SHA-256 manifests.
- Keep every mutable profile, OPFS fixture, receipt, sampler output, and cleanup record inside one ignored run directory. Reject any resolved mutable path outside that ownership root.
- Run three sequential repetitions at 32, 128, 256, and 512 MiB raw selected bytes. Add 1 GiB only if the measured curve does not locate a defensible space/responsiveness boundary.
- Enforce a 1.25 GiB live-owned cap and 16 GiB untouched free-space reserve throughout.
- Exercise the real production workspace pipeline: raw materialization, ZIP store packaging, spool, canonical metadata, close, owned-process cut, same-profile/origin recovery, full readback, and ownership-proven cleanup.
- Record exact checked cost components, actual profile/OPFS peak, storage estimate/quota facts, timings, identities, failures, output digest/length, recovery evidence, and zero-remainder cleanup proof.
- Supply precomputed complete discovery. Recommendation evaluation itself must not scan, grant authority, create a target, freeze a threshold, or emit a production digest.
- The threshold candidate is expressed in exact checked workspace peak-budget bytes, not merely raw selected bytes. It must remain below existing hard admission limits and be supported by three successful repetitions plus recovery/cleanup at every included scale.
- There is no pre-authorized latency number or desired threshold. Propose a boundary from the measured cost/peak/responsiveness curve and product UX; if no defensible boundary appears, run the optional 1 GiB case or report insufficiency. Do not reverse-fit the evidence to a preferred value.

Only a later independent review may freeze the candidate.
